Columnas de tiempo:
- created_t: fecha/hora real en la que el registro fue creado por la aplicacion.
- pin_virtual_time_t: fecha/hora virtual vigente en el momento de la operacion de negocio.

Importante:
- created_t no debe cambiar cuando se mueve el pin virtual time.
- pin_virtual_time_t permite saber con que fecha virtual se creo una cuenta, pago, reembolso,
  disputa, producto, servicio, cargo de billing o evento.
- Algunas tablas conservan created_at por compatibilidad con consultas existentes; para auditoria
  tecnica usa created_t y para fecha logica usa pin_virtual_time_t.

SELECT
    b.bill_no,
    bi.bill_info_no,
    a.id AS account_id,
    a.owner_name,
    br.run_code AS billing_run_no,
    br.virtual_time AS billing_virtual_time,
    i.id AS item_id,
    i.item_no,
    i.item_type,
    i.status AS item_status,
    i.amount,
    i.currency,
    i.item_date,
    i.created_t AS item_created_t,
    i.pin_virtual_time_t AS item_pin_virtual_time_t,
    bc.id AS billing_charge_id,
    p.code AS product_code,
    p.name AS product_name,
    s.service_code,
    bc.transaction_id
FROM bills_t b
JOIN billinfo_t bi ON bi.id = b.billinfo_id
JOIN accounts_t a ON a.id = b.account_id
JOIN items_t i ON i.bill_id = b.id
JOIN billing_charges_t bc ON bc.id = i.billing_charge_id
JOIN billing_runs_t br ON br.id = bc.billing_run_id
JOIN products_t p ON p.id = i.product_id
LEFT JOIN services_t s ON s.id = i.service_id
WHERE b.bill_no = 'AQUI_BILL_NO'
ORDER BY i.item_date ASC, i.id ASC;

43. Migracion opcional: actualizar CHECK de eventos en PostgreSQL

-- Ejecuta esto si la creacion de cuentas falla al registrar BILLINFO_CREATED.
-- La aplicacion ya intenta hacerlo automaticamente al iniciar, pero esta consulta sirve para
-- corregir la base manualmente si el usuario de PostgreSQL no tiene permisos de ALTER TABLE.

DO $$
DECLARE
    constraint_record record;
BEGIN
    FOR constraint_record IN
        SELECT nsp.nspname, rel.relname, con.conname
        FROM pg_constraint con
        JOIN pg_class rel ON rel.oid = con.conrelid
        JOIN pg_namespace nsp ON nsp.oid = rel.relnamespace
        WHERE rel.relname = 'system_events_t'
          AND con.contype = 'c'
          AND pg_get_constraintdef(con.oid) ILIKE '%type%'
    LOOP
        EXECUTE format(
            'ALTER TABLE %I.%I DROP CONSTRAINT %I',
            constraint_record.nspname,
            constraint_record.relname,
            constraint_record.conname
        );
    END LOOP;
END $$;
